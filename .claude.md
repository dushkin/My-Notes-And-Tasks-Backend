# Backend Agent Guidelines - NoTask

**Role**: Implement Express API, MongoDB models, server-side logic, and Socket.IO events
**Never touch**: Frontend code, React components, client-side hooks

## Tech Stack

- **Runtime**: Node.js 18+ with ES modules
- **Framework**: Express.js
- **Database**: MongoDB with Mongoose
- **Authentication**: JWT (access + refresh tokens)
- **Encryption**: mongoose-field-encryption for sensitive data
- **Real-time**: Socket.IO server
- **Security**: Helmet, CORS, rate limiting, XSS sanitization
- **File Upload**: Multer + Sharp (image processing)
- **Push Notifications**: Firebase Admin SDK
- **Logging**: Winston
- **Testing**: Jest + Supertest

## Critical Rules

### MongoDB Field Encryption

**CRITICAL**: The `notesTree` field is encrypted via `mongoose-field-encryption` plugin.

```javascript
// User.js
userSchema.plugin(fieldEncryption, {
    fields: ['notesTree'],
    secret: process.env.DATA_ENCRYPTION_SECRET
});
```

**Encryption Plugin Requirements**:
- ❌ **NEVER use `.select('notesTree')`** - breaks decryption
- ✅ **ALWAYS fetch full user document** - encryption plugin needs all fields
- ❌ **NEVER use `.lean()`** - bypasses encryption middleware
- ✅ **Use `.lean(false)`** or omit it entirely

**Wrong**:
```javascript
// This returns EMPTY ARRAY - encryption fails!
const user = await User.findById(userId).select('notesTree');
console.log(user.notesTree); // []
```

**Correct**:
```javascript
// Fetch full document for proper decryption
const user = await User.findById(userId);
console.log(user.notesTree); // [actual tree data]
```

### Tree Operations ([controllers/itemsController.js](controllers/itemsController.js))

**All tree mutations follow this pattern**:

1. Fetch user document (full, not `.select()`)
2. Find item in tree using `findItemRecursive()`
3. Validate operation (permissions, name conflicts, etc.)
4. Update tree in memory
5. Save to database
6. Emit Socket.IO event for real-time sync
7. Return updated item to client

**Example - Update Item**:
```javascript
export const updateItem = catchAsync(async (req, res, next) => {
    const userId = req.user.id;
    const { itemId } = req.params;
    const updates = req.body;

    // 1. Fetch full user (encryption requirement)
    const user = await User.findById(userId);
    if (!user) return next(new AppError('User not found', 404));

    const currentTree = user.notesTree || [];

    // 2. Find item
    const result = findItemRecursive(currentTree, itemId, 'notesTree');
    if (!result) return next(new AppError('Item not found', 404));

    // 3. Validate
    if (updates.label && hasSiblingWithName(result.parentArray, updates.label, itemId)) {
        return next(new AppError('Name conflict', 400));
    }

    // 4. Update in memory
    const updatedTree = updateItemInTree(currentTree, itemId, updates);

    // 5. Save (two strategies based on update type)
    if (updates.label && Object.keys(updates).length === 1 && result.mongoPath) {
        // Optimization: Use $set for simple label updates
        await User.updateOne(
            { _id: userId },
            { $set: {
                [`${result.mongoPath}.label`]: updates.label,
                [`${result.mongoPath}.updatedAt`]: new Date(),
                [`${result.mongoPath}.version`]: result.item.version + 1
            }}
        );
    } else {
        // Full save for complex updates
        user.notesTree = updatedTree;
        user.markModified('notesTree');
        await user.save({ validateBeforeSave: false });
    }

    // 6. Emit Socket.IO event
    emitToUser(userId, 'item_updated', { itemId, updates });

    // 7. Return updated item
    const updatedItem = findItemRecursive(updatedTree, itemId).item;
    res.status(200).json(updatedItem);
});
```

### Tree Utility Functions ([utils/backendTreeUtils.js](utils/backendTreeUtils.js))

**findItemRecursive(nodes, itemId, path = null)**:
- Recursively searches tree for item by ID
- If `path` is a string (e.g., `'notesTree'`), builds MongoDB dot-notation path
- Returns `{ item, parentArray, mongoPath }` or `null`

**IMPORTANT**: When calling with `path` parameter, it enables mongoPath tracking for `$set` optimizations.

```javascript
// Enable mongoPath tracking
const result = findItemRecursive(tree, itemId, 'notesTree');
// result.mongoPath = 'notesTree.0.children.2' (for example)

// Without path tracking
const result = findItemRecursive(tree, itemId);
// result.mongoPath = undefined
```

**updateItemInTree(tree, itemId, updates)**:
- Updates item properties in memory
- Auto-increments version number
- Sets updatedAt timestamp
- Returns new tree (immutable update)

**deleteItemInTree(tree, itemId)**:
- Removes item from tree
- Returns updated tree

**hasSiblingWithName(siblings, name, excludeId)**:
- Checks for name conflicts in same directory
- Used for validation before create/rename

## Authentication & Authorization

### JWT Strategy

**Access Token**:
- Short-lived (15 minutes)
- Stored in client `localStorage`
- Included in `Authorization: Bearer <token>` header

**Refresh Token**:
- Long-lived (7 days)
- Stored in client `localStorage`
- Used to obtain new access token

**Middleware** ([middleware/authMiddleware.js](middleware/authMiddleware.js)):
```javascript
import jwt from 'jsonwebtoken';

export default function authMiddleware(req, res, next) {
    const token = req.headers.authorization?.split(' ')[1];

    if (!token) {
        return res.status(401).json({ error: 'No token provided' });
    }

    try {
        const decoded = jwt.verify(token, process.env.JWT_SECRET);
        req.user = { id: decoded.userId };
        next();
    } catch (error) {
        return res.status(401).json({ error: 'Invalid or expired token' });
    }
}
```

**All routes except login/register MUST use auth middleware**:
```javascript
// routes/itemsRoutes.js
router.use(authMiddleware);  // Protect all routes below

router.get('/', getNotesTree);
router.post('/', createItem);
// ...
```

## Socket.IO Real-time Sync ([socket/socketController.js](socket/socketController.js))

**Server Setup**:
```javascript
import { Server } from 'socket.io';

const io = new Server(httpServer, {
    cors: {
        origin: process.env.FRONTEND_URL,
        credentials: true
    }
});

// Authenticate socket connections
io.use((socket, next) => {
    const token = socket.handshake.auth.token;
    try {
        const decoded = jwt.verify(token, process.env.JWT_SECRET);
        socket.userId = decoded.userId;
        next();
    } catch (error) {
        next(new Error('Authentication failed'));
    }
});

// Join user-specific room
io.on('connection', (socket) => {
    socket.join(`user_${socket.userId}`);
});
```

**Emitting Events**:
```javascript
// Broadcast to all sockets of a specific user (multi-device sync)
export function emitToUser(userId, event, data) {
    io.to(`user_${userId}`).emit(event, data);
}

// Usage in controllers
emitToUser(userId, 'item_created', { item: newItem });
emitToUser(userId, 'item_updated', { itemId, updates });
emitToUser(userId, 'item_deleted', { itemId });
emitToUser(userId, 'item_moved', { itemId, newParentId, newIndex });
```

**Events to Emit**:
- `tree_updated` - Full tree refresh
- `item_created` - New item added
- `item_updated` - Item modified
- `item_deleted` - Item removed
- `item_moved` - Item repositioned

### Content Sanitization ([utils/contentSanitizer.js](utils/contentSanitizer.js))

**XSS Prevention**:
```javascript
import DOMPurify from 'isomorphic-dompurify';

export function sanitizeContent(html) {
    return DOMPurify.sanitize(html, {
        ALLOWED_TAGS: ['p', 'strong', 'em', 'u', 'ul', 'ol', 'li', 'br'],
        ALLOWED_ATTR: []
    });
}
```

**Apply to rich text content BEFORE saving**:
```javascript
if (updates.content && typeof updates.content === 'string') {
    updates.content = sanitizeContent(updates.content);
}
```

## Error Handling ([middleware/errorHandlerMiddleware.js](middleware/errorHandlerMiddleware.js))

### AppError Class
```javascript
export class AppError extends Error {
    constructor(message, statusCode) {
        super(message);
        this.statusCode = statusCode;
        this.isOperational = true;
    }
}
```

### catchAsync Wrapper
```javascript
export const catchAsync = (fn) => {
    return (req, res, next) => {
        fn(req, res, next).catch(next);
    };
};
```

**Usage**:
```javascript
export const createItem = catchAsync(async (req, res, next) => {
    // If any error is thrown, catchAsync passes it to error handler
    const user = await User.findById(userId);
    if (!user) {
        return next(new AppError('User not found', 404));
    }
    // ...
});
```

### Global Error Handler
```javascript
export function globalErrorHandler(err, req, res, next) {
    err.statusCode = err.statusCode || 500;
    err.status = err.status || 'error';

    if (process.env.NODE_ENV === 'production') {
        res.status(err.statusCode).json({
            status: err.status,
            message: err.message
        });
    } else {
        res.status(err.statusCode).json({
            status: err.status,
            message: err.message,
            stack: err.stack
        });
    }
}
```

## Performance Optimization

### MongoDB Query Optimization

**Use $set for targeted updates**:
```javascript
// Fast - updates only specific fields
await User.updateOne(
    { _id: userId },
    { $set: { 'notesTree.0.label': 'New Label' } }
);

// Slow - replaces entire document
user.notesTree = updatedTree;
await user.save();
```

**When to use each**:
- `$set`: Label-only updates, simple property changes
- `.save()`: Complex updates, multiple nested changes, validation required

### Indexing

Ensure indexes on frequently queried fields:
```javascript
userSchema.index({ email: 1 });  // Login queries
userSchema.index({ createdAt: -1 });  // Sorting
```

## Common Pitfalls

⚠️ **Encryption + .select()**: Using `.select('notesTree')` returns empty array - always fetch full document
⚠️ **Socket.IO Auth**: Verify JWT in socket handshake before allowing connection
⚠️ **Tree Mutations**: Always emit Socket.IO events after successful DB save
⚠️ **Winston Logs**: In production, use `console.log()` alongside `logger.info()` for Render visibility
⚠️ **Version Control**: Increment version on content updates to detect conflicts
⚠️ **Rate Limiting**: Apply to write endpoints to prevent abuse
⚠️ **CORS**: Whitelist frontend URL, never use `*` in production
